# Upstream issues — the 3.x direction

Local copies of the two open issues from [nelkor/passcryptum](https://github.com/nelkor/passcryptum)
(the 2.x project this repository continues; see README). Upstream development
stopped at v2.1.4; these issues sketched what 3.x was supposed to become.

- `187.md` — "Services on The Server": the server-sync design (entropy layout,
  tweetnacl/Ed25519, request framing, online PIN + protector).
  **Implemented in 3.0** — the whole backend and the online mode are this issue
  turned into code.
- `159.md` — "Make a new layout": new UI based on the Figma design.
  **Open** — the 3.x backlog starts here.
