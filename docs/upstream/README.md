# Upstream issues — the 3.x direction

Local copies of the two open issues from
[nelkor/passcryptum](https://github.com/nelkor/passcryptum) — the 2.x project
this repository continues (see the root README). Upstream development stopped
at v2.1.4; these issues sketched what 3.x was supposed to become. They are
kept here because the upstream tracker may disappear.

- [187 — Services on The Server](187-services-on-the-server.md): the
  server-sync design (entropy layout, tweetnacl/Ed25519, request framing,
  online PIN + protector). **Implemented in 3.0** — the whole backend and the
  online mode are this issue turned into code.
- [159 — Make a new layout](159-new-layout.md): new UI based on the Figma
  design. **Open** — the 3.x backlog starts here.
